开源项目

把 Morning Brief 安装在你自己的环境里。

Morning Brief 是一个自托管研究工作流。它抓取每日市场与 AI 产业信息，对候选内容评分和去重，再把筛选结果写入 Telegram 与 Obsidian。

已开源

MIT 许可 · Python 3.10+ · 使用你自己的 API Key

01

它是一套可以运行的工作流，不是交易信号。

公开仓库包含完整 pipeline、信源配置、评分方法、输出格式、示例和 Skill 规范。你需要把它运行在自己的电脑或服务器上。

核心任务
把每天的信息流整理成保留来源的研究队列。
输出位置
Telegram 简报，以及 Obsidian Vault 里的结构化 Markdown。
需要准备
一个 LLM API、Telegram Bot 和可以写入的本地 Vault。
不包含
它不是托管 API 或一键安装的 Codex 插件，也不提供交易执行或收益保证。
打开 GitHub 仓库查看 SKILL.md

02

四步完成首次安装。

下面的流程会先建立独立 Python 环境，把密钥保留在本地，并在真正推送或写入之前完成环境检查与干跑。

安装前准备

  • Python 3.10 或更高版本
  • Kimi 或 Anthropic API Key
  • Telegram Bot Token 与 Chat ID
  • Obsidian Vault 的绝对路径
  1. 01

    克隆公开仓库

    git clone https://github.com/dreamybecca-coder/invert-morning-brief.git
cd invert-morning-brief
  2. 02

    建立独立运行环境

    python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
  3. 03

    填写本地配置

    cp .env.example .env
# 打开 .env，填入你自己的密钥和路径
  4. 04

    先检查，再进行干跑

    python scripts/validate.py --check-all
python run_morning_brief.py --dry-run --date today
