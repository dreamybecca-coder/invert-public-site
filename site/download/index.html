Choose the right version

Not sure which download you need?

  • On a Mac, open Apple menu > About This Mac. If the chip begins with M1, M2, M3 or M4, choose macOS.
  • On Windows, open Settings > System > About and check that System type says 64-bit operating system.
  • On a phone or tablet? Return to this page on the computer where you want to install INVERT.
