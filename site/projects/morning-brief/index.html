Open-source project

Run Morning Brief in your own environment.

Morning Brief is a self-hosted research workflow. It filters daily market and AI industry information, scores and deduplicates the candidates, then writes selected outputs to Telegram and Obsidian.

Open source

MIT licensed · Python 3.10+ · Bring your own API keys

01

A runnable workflow, not a trading signal.

The public repository contains the pipeline, source configuration, scoring method, output format, examples and Skill specification. You run it locally or on infrastructure you control.

Primary job
Turn a daily information stream into a traceable research queue.
Outputs
Telegram briefs and structured Markdown in an Obsidian vault.
Required services
An LLM API, a Telegram bot and a writable local vault.
Not included
It is not a hosted API or one-click Codex plugin, and it does not provide trade execution or a return guarantee.

02

Install it in four steps.

The commands below create an isolated Python environment, preserve your secrets locally and validate the setup before any output is sent.

Before you begin

  • Python 3.10 or newer
  • Kimi or Anthropic API key
  • Telegram bot token and chat IDs
  • Absolute path to an Obsidian vault
  1. 01

    Clone the public repository

    git clone https://github.com/dreamybecca-coder/invert-morning-brief.git
cd invert-morning-brief
  2. 02

    Create an isolated environment

    python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
  3. 03

    Add your local configuration

    cp .env.example .env
# Open .env and add your own keys and paths
  4. 04

    Validate, then run without publishing

    python scripts/validate.py --check-all
python run_morning_brief.py --dry-run --date today
